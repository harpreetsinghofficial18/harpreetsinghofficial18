## Featured Project

Developed as part of a five-member analytics project focused on forecasting passenger demand and supporting operational planning for the Port Authority Bus Terminal.

**Project highlights:**

- Analyzed recovery relative to the 2019 pre-COVID baseline

- Developed carrier-level forecasts
- Identified projected peak travel periods
- Built an interactive Power BI analytics dashboard
